## 🚀 About This Portfolio

Welcome to my centralized **Cloud Computing Engineering Portfolio**! This repository documents my hands-on technical progression throughout the **CCM101 (Cloud Computing)** course at the **University of Eastern Pangasinan**.

Structured around a real-world simulation at **CloudNova Technologies**, each laboratory mission represents an engineering promotion—advancing from foundational Linux server auditing and cloud architecture blueprinting to multi-cloud consulting (AWS, Azure, GCP), Docker containerization, S3-compatible object storage (MinIO), multi-tier Infrastructure as Code (Docker Compose), and Site Reliability Engineering (SRE) observability.

<summary><b>🐳 Laboratory 04: The Cloud-Native Engineer (Docker & Container Lifecycle)</b></summary>
<br/>

* **Role:** Cloud-Native Engineering Team at CloudNova Technologies.
* **Objective:** Demonstrate the architectural advantages of lightweight containers over traditional Virtual Machines by deploying, exposing, verifying, stopping, and removing a containerized Nginx web server in seconds.
* **Key Commands Executed:** `docker --version`, `docker info`, `docker pull nginx`, `docker run -d -p 8080:80 --name my-web-server nginx`, `curl http://localhost:8080`, `docker ps`, `docker stop`, `docker rm`.
* **Deliverables:**
  * 📄 [Laboratory 04 README](./Laboratory-04-Cloud-Native-Engineer/README.md)
  * 📄 [Virtualization vs. Containers Analysis](./Laboratory-04-Cloud-Native-Engineer/virtualization-vs-containers.md)

</details>

<details>
<summary><b>🗄️ Laboratory 05: The Cloud Data Engineer (MinIO S3 Object Storage)</b></summary>
<br/>

* **Deliverables:**

</details>

<details>
<summary><b>🏗️ Laboratory 06: The Cloud Deployment Engineer (Docker Compose & IaC)</b></summary>
<br/>

* **Role:** Cloud Deployment Team at CloudNova Technologies.
* **Objective:** Transition from imperative CLI commands to declarative Infrastructure as Code (IaC) by writing a `docker-compose.yml` file to deploy a two-tier private cloud storage stack (Nextcloud web frontend + MariaDB database backend).
* **Key Commands Executed:** `nano docker-compose.yml`, `docker-compose up -d`, `docker-compose ps`, `docker-compose down`.
* **Deliverables:**
  * 📄 [Laboratory 06 README](./Laboratory-06-Cloud-Deployment-Engineer/README.md)

<summary><b>📈 Laboratory 07: The Cloud Operations Engineer (SRE Observability & Monitoring)</b></summary>
<br/>

* **Role:** Cloud Operations / Site Reliability Engineering (SRE) Team at CloudNova Technologies.
* **Objective:** Establish a host hardware performance baseline, deploy a production Nginx container (`client-website`), simulate valid (`HTTP 200`) and invalid (`HTTP 404`) user traffic, and audit container health via application logs and real-time resource metrics.
* **Key Commands Executed:** `free -h`, `df -h`, `top`, `curl http://localhost:8080`, `curl http://localhost:8080/hidden-admin-page`, `docker logs client-website`, `docker stats`.
* **Deliverables:**
