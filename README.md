## 🚀 About This Portfolio

Welcome to my centralized **Cloud Computing Engineering Portfolio**! This repository documents my hands-on technical progression throughout the **CCM101 (Cloud Computing)** course at the **University of Eastern Pangasinan**.

Structured around a real-world simulation at **CloudNova Technologies**, each laboratory mission represents an engineering promotion—advancing from foundational Linux server auditing and cloud architecture blueprinting to multi-cloud consulting (AWS, Azure, GCP), Docker containerization, S3-compatible object storage (MinIO), multi-tier Infrastructure as Code (Docker Compose), and Site Reliability Engineering (SRE) observability.
