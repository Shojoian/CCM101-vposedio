# 🛡️ Security Audit Report & Best Practices

### 1. The Principle of Least Privilege (PoLP)
The Principle of Least Privilege dictates that a user, account, or process should only be granted the bare minimum privileges and access permissions necessary to perform its specific job functions[cite: 18].

### 2. Attack Surface
The attack surface refers to all possible entry points, exposed network ports, and running services through which an unauthorized user can try to access or extract data from a virtual machine[cite: 18, 19].

### 3. Default Deny Policy
A Default Deny firewall policy automatically blocks all incoming network traffic unless an explicit exception rule is created, making it far safer than trying to block individual hackers manually.
