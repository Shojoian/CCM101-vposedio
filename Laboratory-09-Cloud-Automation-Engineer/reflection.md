# 💭 Mission Reflection: Cloud Automation
1. Automation is critical because manual administration does not scale across hundreds of servers.
2. A destructive typo in an automated script can cause enterprise-wide data loss instantly.
3. Bash scripts are imperative procedural programs, whereas Docker Compose files are declarative state blueprints[cite: 13, 25].
4. The portfolio successfully transitions from basic cloud concepts to multi-cloud, containerization, IaC, security, and automation[cite: 9, 14, 18, 22].
5. The Cloud-Native and Deployment Engineer roles were most engaging because containerization bridges development and operations[cite: 9, 13].
