# 🤖 Automation Research & Scripting Theory

### 1. Bash Scripting and the Shebang (`#!/bin/bash`)
A Bash script is a plain-text file executed sequentially by the shell[cite: 22]. The shebang tells the OS kernel which interpreter binary to use.

### 2. Variables in Automation Scripts
Variables (like `SOURCE_DIR`) store dynamic paths in a central location, preventing typos and simplifying maintenance.

### 3. Cron Jobs and Task Scheduling
Cron is a time-based task scheduler in Unix systems that automates repetitive maintenance tasks like backups without human intervention[cite: 22, 23].
