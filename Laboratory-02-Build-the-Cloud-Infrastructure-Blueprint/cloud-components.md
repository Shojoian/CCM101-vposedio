# Cloud Infrastructure Components

### 1. Compute Resources
* **Purpose:** Provides processing power (CPU/RAM) to execute applications.
* **Importance:** Compute is the core engine that drives digital services, allowing scaling without buying physical hardware.
* **Relation to KillerCoda:** Represented by our 1 CPU core and 1.9Gi of RAM running our Linux terminal environment.

### 2. Storage Resources
* **Purpose:** Provides persistent and temporary locations to store data and files.
* **Importance:** Ensures high availability, automated backups, and scalable access for massive files.
* **Relation to KillerCoda:** Represented by the virtual block storage drives holding the operating system.

### 3. Networking Resources
* **Purpose:** Establishes pathways for data communication between virtual servers and the internet.
* **Importance:** Provides connectivity and security boundaries (firewalls, routing).
* **Relation to KillerCoda:** Represented by our 172.30.1.2 IP address and network interfaces enabling our browser connection.

### 4. Operating System (OS)
* **Purpose:** Acts as the software layer managing physical hardware and user applications.
* **Importance:** Abstracts hardware management and provides the hosting environment for cloud apps.
* **Relation to KillerCoda:** The environment runs Ubuntu Linux, providing our command-line utilities.
