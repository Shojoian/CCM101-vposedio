# Mission Reflection

**1. Which component is most important?**
Compute is foundational. Without processor execution, networking cannot route traffic and data remains unused.

**2. How does Linux support cloud computing?**
Its lightweight footprint, open-source modularity, and stability make it the ideal OS for hypervisors and cloud instances.

**3. Why is documentation important?**
It provides a structural blueprint to prevent misconfigurations and establishes a troubleshooting baseline for maintenance.

**4. What new skills did you learn?**
I gained proficiency with Linux hardware commands (`lscpu`, `free -h`, `df -h`) and learned how to map physical compute layers to AWS, Azure, and GCP equivalents.

**5. How has your GitHub improved?**
My repository now reflects a professional engineering structure by organizing markdown reports and visual blueprints cleanly.
