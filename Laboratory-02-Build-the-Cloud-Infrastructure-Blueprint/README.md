# Laboratory 2: Build the Cloud Infrastructure Blueprint

## Mission Overview
Simulating the planning phase of a cloud migration for CloudNova Technologies by mapping physical hardware to cloud concepts.

## Objectives
* Investigate Linux hardware and differentiate cloud resources.
* Compare AWS, Azure, and GCP equivalent services.

## Cloud Infrastructure Components
* **Compute:** CPU/RAM.
* **Storage:** Disk drives and file systems.
* **Networking:** IP addresses and routing.
* **OS:** Ubuntu Linux.

## Tools Used
* KillerCoda Playground, GitHub, Markdown, Draw.io

## Linux Commands Executed
`cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`, `hostname`, `ip a`.

## Skills Learned
Mapping infrastructure layers natively via Linux CLI to public cloud offerings.

## Challenges Encountered
Navigating directory structures and properly committing Git repositories through the CLI.
