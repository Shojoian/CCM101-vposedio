# Microsoft Azure

* **Brief Overview:** Launched in 2010, Microsoft Azure is a massive public cloud designed with a heavy focus on enterprise and hybrid integrations.
* **Global Infrastructure:** Features a vast network of over 60 global regions designed to meet strict enterprise data compliance requirements.
* **Cloud Management Console:** The Azure Portal is a unified hub allowing users to build, manage, and monitor all Azure services.
* **Four Core Services:** Azure Virtual Machines (Compute), Azure Blob Storage (Storage), Azure Virtual Network (Networking), Microsoft Entra ID (Identity).
* **Three Advantages:** Seamless integration with Windows/Office 365, industry-leading hybrid cloud capabilities, and strong enterprise security.
* **Typical Enterprise Use Cases:** Migrating legacy on-premises Windows Active Directory servers to the cloud and hybrid deployments.
