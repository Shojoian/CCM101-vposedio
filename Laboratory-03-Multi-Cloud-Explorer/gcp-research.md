# Google Cloud Platform (GCP)

* **Brief Overview:** Launched in 2008, GCP runs on the same underlying infrastructure that powers Google’s end-user products like Search and YouTube.
* **Global Infrastructure:** Connects global Regions through Google's massive, private fiber-optic network for extremely low-latency routing.
* **Cloud Management Console:** The Google Cloud Console provides a clean, developer-friendly web interface to manage deployments.
* **Four Core Services:** Google Compute Engine (Compute), Google Cloud Storage (Storage), Google Virtual Private Cloud (Networking), Google Cloud IAM (Identity).
* **Three Advantages:** Recognized leader in open-source Kubernetes, unparalleled data analytics tools, and competitive pricing for sustained workloads.
* **Typical Enterprise Use Cases:** Training complex machine learning models and processing massive big data pipelines.
