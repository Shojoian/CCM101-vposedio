# Amazon Web Services (AWS)

* **Brief Overview:** AWS is a comprehensive, evolving cloud platform provided by Amazon, leading the public cloud industry since 2006.
* **Global Infrastructure:** Comprises 105 Availability Zones within 33 geographic regions around the world for fault tolerance.
* **Cloud Management Console:** The AWS Management Console provides a secure web interface to provision and monitor resources.
* **Four Core Services:** Amazon EC2 (Compute), Amazon S3 (Storage), Amazon VPC (Networking), AWS IAM (Identity).
* **Three Advantages:** Unmatched service breadth, massive global footprint, and a highly mature ecosystem of enterprise partners.
* **Typical Enterprise Use Cases:** Massive-scale media streaming, enterprise cloud migrations, and dynamic gaming servers.
