# Laboratory Activity 1: Welcome to the Cloud

## Mission Overview
Setup cloud workspace, learn basic Linux command-line operations, explore system information, and construct a structured GitHub portfolio repository.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate Linux OS.
- Gather system information and organize file structures.
- Maintain a professional GitHub portfolio with Markdown documentation.

## Activities Performed
- User creation and privileges setup (vposedio).
- Environment exploration and hardware/OS metrics collection.
- Directory structure layout inside home directory.
- GitHub repository creation and setup.

## Linux Commands Used
useradd, usermod, passwd, su, whoami, pwd, hostname, mkdir, cat, lsb_release, uname, lscpu, free, df, git

## Skills Learned
- Managing users and permissions in Linux.
- Collecting system information via shell commands.
- Structuring projects using Git and Markdown.
